By default this tutor runs entirely offline using a built-in knowledge base — no setup, no API key, no cost. Claude's API is designed to be called from a server, not directly from a browser, so this page can't reach it on its own.

To get real Claude-powered answers instead of the local engine, run the tiny local proxy included next to this file:

  1. Get an API key at console.anthropic.com (this uses your own paid account).
  2. In a terminal, in this folder, set the key and start the proxy — it never leaves your computer:
set ANTHROPIC_API_KEY=sk-ant-your-key-here
node ai-proxy-server.js

Then tick the box below. Every message will try your local proxy first and automatically fall back to the offline engine if it isn't running.
